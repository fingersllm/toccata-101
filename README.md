# campaign-state

This branch is written by the Toccata 101 crowdfund's keeper, and by nothing else. Each file is a campaign's public
account, `<network>/<campaign>.json`: the vault, the counted coins, the pledges waiting, the network's clock and the
last chain block the keeper read. The campaign page reads them; anyone can check them against the chain.

The site is built from `main`, which this branch never touches.
